# Workshop visuals

- `healthcare-gateway-hero.png`: original conceptual art created with the built-in image generation tool. It is not an architecture diagram or a product screenshot.
- `../diagrams/*.svg`: editable local diagrams. Existing architecture/identity/control illustrations were retained and corrected; seven new figures explain request flow, token types, authorization outcomes, rollout, content screening, PHI boundaries, and private MCP ingress.

Final hero prompt (built-in tool):

> Use case: illustration-story. Asset type: wide editorial cover illustration for a hands-on healthcare agent gateway coding workshop. Primary request: show a clinician at a workstation sending a request to a small helpful software agent, a distinct protective gateway between that agent and a vault of synthetic medical records, with a separate clinical guideline reference library nearby. Style: polished isometric editorial illustration, approachable and precise, subtle paper grain, ivory background, deep navy structures, teal connectivity, amber clinician credential accents. Composition: wide landscape, balanced architecture, clear large forms, generous whitespace, no tiny details. Include a shield motif at the gateway and a separate key motif at the records vault to suggest two independent access checks. No lettering, no logos, no real patient information, no UI screenshots, no claims of clinical efficacy. This is conceptual art, not a technical diagram.
